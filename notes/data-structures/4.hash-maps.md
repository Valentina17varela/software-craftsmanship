# Hash Maps

## 1. Description and declaration

A hash map stores key-value pairs and uses a hash function to locate values efficiently. Keys are unique; assigning an existing key replaces its previous value.

Python uses `dict`. TypeScript uses `Map<K, V>` for arbitrary key types and predictable map behavior. Plain objects are also common for string keys, but `Map` is generally clearer for algorithms.

### Python

```python
scores = {"Ada": 95, "Linus": 88}
scores["Grace"] = 91

print(scores["Ada"])       # 95
print("Grace" in scores)   # True
```

### TypeScript

```typescript
const scores = new Map<string, number>([
    ["Ada", 95],
    ["Linus", 88],
]);
scores.set("Grace", 91);

console.log(scores.get("Ada")); // 95
console.log(scores.has("Grace")); // true
```

### Key properties

- Each key maps to at most one value.
- Lookup, insertion, and deletion are $O(1)$ on average.
- Hash collisions can degrade operations to $O(n)$ in the worst case.
- Keys must be hashable in Python; mutable containers such as lists cannot be dictionary keys.
- JavaScript and TypeScript `Map` accepts primitive and object keys.
- Both Python dictionaries and TypeScript maps preserve insertion order.

## 2. Complexity model

Throughout this document, $n$ is the number of stored key-value pairs.

### General rules

1. Lookup, insertion, update, and deletion are $O(1)$ on average.
2. Iteration is $O(n)$.
3. Resizing occasionally costs $O(n)$, but insertion remains amortized $O(1)$.
4. Worst-case collision behavior can make a single operation $O(n)$.
5. The map uses $O(n)$ additional space.

### Complexity summary

| Operation | Average time | Worst-case time | Extra space |
| --- | ---: | ---: | ---: |
| Lookup by key | $O(1)$ | $O(n)$ | $O(1)$ |
| Insert or update | $O(1)$ amortized | $O(n)$ | $O(1)$ amortized |
| Delete by key | $O(1)$ | $O(n)$ | $O(1)$ |
| Membership check | $O(1)$ | $O(n)$ | $O(1)$ |
| Length | $O(1)$ | $O(1)$ | $O(1)$ |
| Iterate keys or values | $O(n)$ | $O(n)$ | $O(1)$ excluding output |
| Copy map | $O(n)$ | $O(n)$ | $O(n)$ |

## 3. Competitive programming use cases

### When to use hash maps

Use a hash map when a problem requires:

- Fast membership or lookup by a non-contiguous key.
- Counting frequencies.
- Remembering the index where a value appeared.
- Grouping values by a computed property.
- Caching previously computed results.
- Mapping graph labels to adjacency lists.
- Detecting duplicates or matching complements.

### Common problem patterns

| Problem type | Stored mapping | Typical complexity |
| --- | --- | ---: |
| Two Sum | Value to index | $O(n)$ |
| Frequency counting | Value to count | $O(n)$ |
| Group anagrams | Signature to list of words | $O(n \cdot k \log k)$ |
| Longest unique substring | Character to latest index | $O(n)$ |
| Prefix-sum subarray count | Prefix sum to frequency | $O(n)$ |
| Memoization | State to result | Problem-dependent |
| Graph adjacency list | Node to neighbors | $O(V + E)$ storage |

### Example: frequency counting

```python
# Python
numbers = [1, 2, 2, 3, 2, 1]
frequency = {}

for number in numbers:
    frequency[number] = frequency.get(number, 0) + 1

print(frequency)  # {1: 2, 2: 3, 3: 1}
```

```typescript
// TypeScript
const numbers: number[] = [1, 2, 2, 3, 2, 1];
const frequency = new Map<number, number>();

for (const number of numbers) {
    frequency.set(number, (frequency.get(number) ?? 0) + 1);
}

console.log(Object.fromEntries(frequency)); // { 1: 2, 2: 3, 3: 1 }
```

### Example: Two Sum

Store each number after checking whether its complement has already appeared. This finds a pair in one traversal.

```python
# Python
numbers = [2, 7, 11, 15]
target = 9
seen = {}
answer = None

for index, number in enumerate(numbers):
    complement = target - number
    if complement in seen:
        answer = [seen[complement], index]
        break
    seen[number] = index

print(answer)  # [0, 1]
```

```typescript
// TypeScript
const numbers: number[] = [2, 7, 11, 15];
const target = 9;
const seen = new Map<number, number>();
let answer: [number, number] | null = null;

for (let index = 0; index < numbers.length; index += 1) {
    const number = numbers[index];
    const complement = target - number;

    if (seen.has(complement)) {
        answer = [seen.get(complement)!, index];
        break;
    }
    seen.set(number, index);
}

console.log(answer); // [0, 1]
```

Both examples take $O(n)$ time and $O(n)$ extra space.

## 4. Operations cheatsheet

| Operation | Python `dict` | TypeScript `Map` | Average time |
| --- | --- | --- | ---: |
| Declare | `items = {"a": 1}` | `new Map([["a", 1]])` | $O(1)$ |
| Empty map | `items = {}` | `new Map()` | $O(1)$ |
| Length | `len(items)` | `items.size` | $O(1)$ |
| Read value | `items[key]` | `items.get(key)` | $O(1)$ |
| Read with default | `items.get(key, default)` | `items.has(key) ? items.get(key) : defaultValue` | $O(1)$ |
| Insert or update | `items[key] = value` | `items.set(key, value)` | $O(1)$ amortized |
| Contains key | `key in items` | `items.has(key)` | $O(1)$ |
| Delete key | `del items[key]` | `items.delete(key)` | $O(1)$ |
| Safe delete | `items.pop(key, None)` | `items.delete(key)` | $O(1)$ |
| Iterate keys | `for key in items:` | `for (const key of items.keys())` | $O(n)$ |
| Iterate values | `for value in items.values():` | `for (const value of items.values())` | $O(n)$ |
| Iterate entries | `for key, value in items.items():` | `for (const [key, value] of items)` | $O(n)$ |
| Clear | `items.clear()` | `items.clear()` | $O(n)$ |
| Shallow copy | `items.copy()` | `new Map(items)` | $O(n)$ |

### Quick examples

```python
# Python
inventory = {"apple": 2}
inventory["apple"] = inventory.get("apple", 0) + 1
inventory["pear"] = inventory.get("pear", 0) + 1

for item, count in inventory.items():
    print(item, count)
```

```typescript
// TypeScript
const inventory = new Map<string, number>([["apple", 2]]);
inventory.set("apple", (inventory.get("apple") ?? 0) + 1);
inventory.set("pear", (inventory.get("pear") ?? 0) + 1);

for (const [item, count] of inventory) {
    console.log(item, count);
}
```

## 5. Important considerations

### Distinguish missing keys from stored falsy values

Use membership checks when `0`, `false`, an empty string, or `undefined` could be a valid stored value. In TypeScript, `map.get(key) ?? defaultValue` is safer than `map.get(key) || defaultValue` when zero is valid.

### Object keys use identity in TypeScript maps

Two separate object literals with identical contents are different keys. Convert structured data to a stable primitive representation when value-based equality is required.

### Dictionary and map copies are shallow

`dict.copy()` and `new Map(existingMap)` create a new outer map, but nested arrays and objects remain shared.

### Do not rely on worst-case constant time

Hash maps provide expected $O(1)$ operations. Adversarial collisions or implementation details can produce worse behavior, although built-in runtimes include collision protections.

### Use arrays for small contiguous key ranges

When keys are integers in a known small range, a frequency array is often faster, simpler, and more memory-efficient than a hash map.
