# Sets

## 1. Description and declaration

A set is an unordered collection of unique values. It is designed for fast membership checks, insertion, deletion, deduplication, and mathematical set operations.

Python uses `set`. TypeScript uses `Set<T>`. Both are commonly implemented with hash tables.

In Python, both `{1, 2, 3}` and `set([1, 2, 3])` create a non-empty set. I have to use `set()` for an empty set because `{}` creates an empty dictionary.

### Python

```python
values = set([1, 2, 2, 3])
values.add(4)

print(sorted(values))  # [1, 2, 3, 4]
print(2 in values)  # True
```

### TypeScript

```typescript
const values = new Set<number>([1, 2, 2, 3]);
values.add(4);

console.log([...values]); // [1, 2, 3, 4]
console.log(values.has(2)); // true
```

### Key properties

- Every value appears at most once.
- Membership, insertion, and deletion are $O(1)$ on average.
- Sets do not support access by index.
- Python set elements must be hashable.
- TypeScript object values are compared by identity, not by contents.
- Python set iteration order is not guaranteed. TypeScript `Set` preserves insertion order, but that order is not sorted order.

## 2. Complexity model

Throughout this document, $n$ and $m$ are the sizes of two sets.

### Complexity summary

| Operation | Average time | Worst-case time | Extra space |
| --- | ---: | ---: | ---: |
| Membership | $O(1)$ | $O(n)$ | $O(1)$ |
| Add | $O(1)$ amortized | $O(n)$ | $O(1)$ amortized |
| Delete | $O(1)$ | $O(n)$ | $O(1)$ |
| Length | $O(1)$ | $O(1)$ | $O(1)$ |
| Iterate | $O(n)$ | $O(n)$ | $O(1)$ excluding output |
| Union | $O(n + m)$ | $O((n + m)^2)$ collision model | $O(n + m)$ |
| Intersection | $O(\min(n,m))$ average | $O(nm)$ | Up to $O(\min(n,m))$ |
| Difference | $O(n)$ average | $O(nm)$ | Up to $O(n)$ |
| Convert array to set | $O(n)$ average | $O(n^2)$ | $O(n)$ |

The worst cases reflect pathological hash collisions. Python generally provides expected constant-time hash operations. JavaScript `Set` complexity is implementation-dependent, although modern runtimes provide similar expected behavior.

## 3. Where this fits in my mental model

### When I reach for sets

I reach for a set when I need:

- Detecting duplicates.
- Tracking values already visited.
- Fast membership checks.
- Finding unique values.
- Computing intersections, unions, or differences.
- Maintaining the distinct values in a sliding window.
- Recording graph or grid nodes that have been visited.

### Common problem patterns

| Problem type | Set usage | Typical complexity |
| --- | --- | ---: |
| Contains duplicate | Values already seen | $O(n)$ average |
| Array intersection | Membership in one input | $O(n + m)$ average |
| Longest unique substring | Current sliding-window values | $O(n)$ average |
| Graph traversal | Visited vertices | $O(V + E)$ |
| Missing or repeated value | Seen values | $O(n)$ average |
| Distinct count | Convert input to set | $O(n)$ average |

### Example: intersection and unique values

```python
# Python
left = [1, 2, 2, 3]
right = [2, 3, 4]

unique = set(left)
intersection = unique & set(right)

print(sorted(unique))        # [1, 2, 3]
print(sorted(intersection))  # [2, 3]
```

```typescript
// TypeScript
const left: number[] = [1, 2, 2, 3];
const right: number[] = [2, 3, 4];

const unique = new Set(left);
const intersection = new Set(right.filter((value) => unique.has(value)));

console.log([...unique].sort((a, b) => a - b));        // [1, 2, 3]
console.log([...intersection].sort((a, b) => a - b));  // [2, 3]
```

### Example: longest unique window

Keep only the values inside the current window. When a duplicate appears, move the left boundary until that duplicate is removed.

```python
# Python
text = "abcabcbb"
window = set()
left = 0
best = 0

for right, character in enumerate(text):
    while character in window:
        window.remove(text[left])
        left += 1
    window.add(character)
    best = max(best, right - left + 1)

print(best)  # 3: "abc"
```

```typescript
// TypeScript
const text = "abcabcbb";
const window = new Set<string>();
let left = 0;
let best = 0;

for (let right = 0; right < text.length; right += 1) {
    const character = text[right];
    while (window.has(character)) {
        window.delete(text[left]);
        left += 1;
    }
    window.add(character);
    best = Math.max(best, right - left + 1);
}

console.log(best); // 3: "abc"
```

Both examples take $O(n)$ average time and $O(n)$ extra space.

## 4. Operations cheatsheet

| Operation | Python | TypeScript | Average time |
| --- | --- | --- | ---: |
| Create | `{1, 2}` or `set([1, 2])` | `new Set([1, 2])` | $O(n)$ |
| Empty set | `values = set()` | `new Set()` | $O(1)$ |
| Length | `len(values)` | `values.size` | $O(1)$ |
| Membership | `value in values` | `values.has(value)` | $O(1)$ |
| Add | `values.add(value)` | `values.add(value)` | $O(1)$ amortized |
| Safe delete | `values.discard(value)` | `values.delete(value)` | $O(1)$ |
| Delete or fail | `values.remove(value)` | Check `delete` result | $O(1)$ |
| Clear | `values.clear()` | `values.clear()` | $O(n)$ |
| Iterate | `for value in values:` | `for (const value of values)` | $O(n)$ |
| Union | `left.union(right)` | `new Set([...left, ...right])` | $O(n + m)$ |
| Intersection | `left & right` | `new Set([...left].filter(x => right.has(x)))` | $O(n)$ average |
| Difference | `left - right` | `new Set([...left].filter(x => !right.has(x)))` | $O(n)$ average |
| Subset | `left <= right` | `[...left].every(x => right.has(x))` | $O(n)$ average |
| Deduplicate array | `list(set(items))` | `[...new Set(items)]` | $O(n)$ average |

## 5. Important considerations

### Sets remove duplicates but may change representation order

I use a set when uniqueness matters. If I also need a sorted result, I sort after conversion. For stable first-occurrence deduplication, I prefer `dict.fromkeys(items)` in Python and `new Set(items)` in TypeScript.

### Reference identity in TypeScript objects

`new Set([{ id: 1 }, { id: 1 }])` contains two objects because they are separate references. Store a primitive key such as `id`, or serialize a stable representation when value-based uniqueness is needed.

### Sets do not count occurrences

When the number of repetitions matters, I use a hash map instead; a set only records whether a value is present.

### Deleting while iterating requires care

Python raises `RuntimeError` when a set changes size during iteration. TypeScript defines how `Set` iteration reacts to deletions, but mutating during traversal can still make the algorithm difficult to reason about. Iterate over a copy when arbitrary deletions are required.

### Hashing has expected, not guaranteed, constant time

Average $O(1)$ behavior is the practical model for challenges, but collisions can produce worse theoretical performance.
